Pick a ready-made layout for your plugin catalog, shop and category pages and assign a template per page.

== Description ==

ForgeHub Product Listings gives you three catalog layouts (Sidebar + Grid, Top Bar + Grid, Category Cards + List) and lets you choose which one is used on the plugins page, the shop page and category pages. Use the [wpfh_product_listing] shortcode to render the assigned template.

== Frequently Asked Questions ==

= Does it need WooCommerce? =
Yes, products are read from WooCommerce.
