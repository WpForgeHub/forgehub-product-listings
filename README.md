**Product Listings** provides modern, responsive, high-converting catalog and archive listing templates with live client-side filtering, debounced search, sorting, and view switching for WooCommerce.

---

## ⚡ Key Highlights

* **3 Modern Free Templates**:
  * **Sidebar + Grid**: Collapsible category taxonomy tree with dynamic item counters on the left, live search, Free/Pro edition tabs, and responsive product grid on the right.
  * **Top Bar + Grid**: Horizontal filter bar with interactive category pill chips, live search, sorting controls, and product cards.
  * **Category Cards + List**: Visual category banner cards on top with dedicated icons and descriptions, paired with flexible list/grid catalog items below.
* **Instant Client-Side Filtering**: Debounced instant keyword search across product titles and excerpts.
* **Edition Switcher**: Filter instantly between All Products, Free items, and Pro editions.
* **Deep URL Synchronization**: Shareable, bookmarkable filter URLs without page reloads (`?pl_search=...&pl_cat=...&pl_edition=...`).
* **Zero External Dependencies**: Pure vanilla JavaScript and native CSS. Zero CDN dependencies or third-party tracking scripts.
* **WCAG 2.1 AA Accessible**: High-contrast, screen-reader friendly typography and ARIA state announcements.

## 🔧 Installation

1. Upload the `forgehub-product-listings` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Configure your preferred catalog template via **Settings &rarr; Product Listings** or embed using the `[forgehub_listing]` shortcode.
